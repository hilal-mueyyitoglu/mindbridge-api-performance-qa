# Attribution and scope

This portfolio is an independently written presentation of learning activities undertaken as part of the Microsoft Junior QA/Software Tester Professional Certificate on Coursera. The original MindBridge learning application and proprietary lab materials are **not redistributed** here.

The reusable Postman collection, JMeter test configuration and portfolio documentation were reconstructed from the learning notes and course exercise instructions to demonstrate test design. They are not represented as original exports or independently verified performance measurements.

The GitHub repository documents educational work performed in a simulated environment, not commercial QA engagements.
